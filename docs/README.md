# CS 개념 정리

`PROJECT_BRIEF.md` 실험을 이해하는 데 필요한 개념만 정리한다.
일반적인 CS 백과사전이 아니라, **이 프로젝트의 측정 결과를 해석하기 위한 배경 지식**이다.

## 작성 규칙

1. 모든 문서는 [`_TEMPLATE.md`](_TEMPLATE.md) 의 7개 섹션 구조를 따른다.
2. **7번 "이 프로젝트에서" 섹션이 채워지지 않는 주제는 쓰지 않는다.** 실험과 연결되지 않으면 이 저장소에 있을 이유가 없다.
3. 숫자에는 근거를 붙인다. "적절히", "충분히", "상황에 따라"로 끝내지 않는다.
4. 측정으로 확인한 내용과 문서에서 읽은 내용을 구분해서 표기한다.
   - 문서/스펙 출처 → `참고` 섹션에 링크
   - 이 프로젝트에서 직접 측정 → `측정값:` 으로 명시
